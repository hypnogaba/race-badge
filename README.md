# Fiber Run for the Solana Breakpoint badge

The badge version of the DoubleZero runner [race.speedlab.pro](https://race.speedlab.pro):
a trader runs along the fiber, a shark bites the cable from below (two bites and you are out),
London on the horizon, and four Edge venue coins (Solana, Kalshi, Hyperliquid, Phoenix)
open the DZ tunnel.

Lua for Solana OS 2.x (ESP32-C5, 320 x 218 screen). Files for the store: `app.json`, `main.lua`, `art.lua`.

## How it is built
- `main.lua`: the game. The run logic is a port of the web game's `sim` package (same numbers,
  60 sim ticks per second, 1 world unit = 2 px), then the screen: a sky rect, the far skyline of each
  world, a drifting landmark, the cable, and pooled images for obstacles, coins and the trader.
  Images only get `pos`/`set`/`show` calls when something changed.
- `art.lua` is generated by `tools/art.py`. Sprites come from `art/web_pixel_sprites.json` (the pixel art of
  the first web version, taken from its git history) plus new ones drawn in `art.py`.
- `tools/sim.py`: the badge API mock (Lua 5.5 via lupa), copied from FORK BOMB.
- `tools/play.py`: a bot plays; prints run length, score and the most VM instructions in one callback.

```
python3 -m venv .venv && .venv/bin/pip install lupa pillow
.venv/bin/python tools/art.py --png
.venv/bin/python tools/play.py --runs 15 --sigma 6
.venv/bin/python tools/play.py --runs 1 --shots tools/out/shots --every 3000
.venv/bin/python tools/bundle.py   # tools/out/bundle.b64 for the emulator page
```

## Numbers (0.1.0)
- Most instructions in one callback: about 6,000 of 200,000.
- Bot medians: timing noise 9 ticks about 11 s, 6 ticks about 27 s, 3.5 ticks several minutes.
